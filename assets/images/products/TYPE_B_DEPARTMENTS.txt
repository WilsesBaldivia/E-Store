HOW TO CHANGE A DEPARTMENT NAME
-------------------------------

1. Open e_storedb.sql.
2. Search for the product SKU, for example TYPEB-COL-08.
3. Change only the product name after "College Type B -".
   Example:
   College Type B - Criminology
   becomes:
   College Type B - College of Criminology
4. Import e_storedb.sql again in phpMyAdmin. The existing product will be
   updated; it will not create a duplicate.

All active Type B products are College-only. The current price (PHP 720.00) and
stock (20 per size) are starter values that the administrator can update later.
